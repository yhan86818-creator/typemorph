Streaming Data into Google BigQuery

Google BigQuery is an incredibly powerful, serverless data warehouse designed for massive-scale analytics. While BigQuery can ingest standard JSON via the bq command line or API, it has very strict requirements: the JSON must be formatted as Newline Delimited JSON (NDJSON). In this format, every JSON object must be flattened onto a single line, separated only by a newline character. When data engineers export logs, analytics events, or database dumps in standard, pretty-printed JSON arrays, they must convert this data into NDJSON before BigQuery will accept it.

The Hassle of Formatting Massive Datasets

Attempting to manually reformat a standard JSON array (e.g., [ { "id": 1 }, { "id": 2 } ]) into Newline Delimited JSON requires removing the outer brackets and stripping out all internal line breaks and indentation. For files containing thousands of records, manual editing or writing custom bash scripts using jq is tedious and disrupts the data ingestion workflow. If a single line break is left inside a JSON object's string value, the BigQuery import job will fail entirely. Automating this transformation ensures immediate compatibility with BigQuery's strict ingestion engine.
